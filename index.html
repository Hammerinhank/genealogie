Éditer les données

Format attendu — un objet avec titre, edition (optionnel) et racine. racine et chaque enfant ont : nom, naissance, deces (optionnels), et éventuellement conjoint ({nom, naissance, deces, mariage}) et enfants (un tableau du même format, avec en plus un id court comme "A", "A.1" pour les repères de branche — facultatif, régénéré sinon). L'éventail se dessine automatiquement : la largeur d'angle de chaque branche est proportionnelle à son nombre de descendants.

Synchronisation GitHub

Propriétaire, dépôt et jeton sont communs à toutes tes généalogies — chacune a son propre fichier dans ce même dépôt (à choisir depuis « 📚 Généalogies »). Le jeton reste uniquement dans le stockage local de ce navigateur (jamais envoyé ailleurs qu'à l'API GitHub) et doit avoir la portée repo. Si le dépôt indiqué n'existe pas encore, l'app tente de le créer automatiquement — cela ne fonctionne que si « Propriétaire » est ton propre compte GitHub.

Sauvegardes

Une sauvegarde est une copie de cette généalogie prise à un instant donné, que tu peux retrouver et récupérer plus tard si besoin.

📱 Sur cet appareil

Un fichier va être proposé au téléchargement juste après — choisis où l'enregistrer (Fichiers, Drive…). C'est normal si une fenêtre du téléphone s'ouvre pour ça.

☁️ Sur GitHub

Aucune sauvegarde GitHub pour l'instant — utilise le bouton ci-dessus (avec un jeton GitHub configuré) pour en créer une, elle apparaîtra ici.

Chaque sauvegarde est enregistrée dans l'historique du fichier de la généalogie sur GitHub (pas de fichier séparé à gérer). Restaurer charge la version choisie dans l'app, sans rien modifier sur GitHub tant que tu n'utilises pas « Enregistrer sur GitHub » ensuite.
